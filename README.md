## ✨ 关于 Echo

**Echo** 是一个基于 AI 技术的灵魂共鸣体生成器。通过 10-15 分钟的深度情感访谈，帮助你探索自我，并生成一个与你真实契合的理想伴侣人格档案与形象。

这不是聊天机器人，而是一次性的深度体验——每个 Echo 都是独一无二的，一旦生成，就永久保存，成为你专属的数字记忆。

### 🌟 核心特点

- **🎯 科学分析** - 基于 Big Five 人格理论（五大人格特质模型），心理学领域最权威的评估框架
- **💫 深度体验** - 25 道专业问卷，涵盖生活作息、社交模式、情绪管理、价值观等维度
- **🎨 完整档案** - 生成包含文字描述和视觉形象的数字人格作品
- **🔒 唯一性** - 每个 Echo 档案都是独特的，生成后不可重置，确保其独特性
- **🖼️ 智能场景生成** - 基于人格档案自动生成多样化场景（商场、书店、电影院、游戏厅、网吧、地铁站等），支持自定义场景描述

## 🎭 使用流程

### 1️⃣ 开始访谈
访问首页，点击「开始探索」，进入灵魂访谈环节。

### 2️⃣ 回答问卷
认真回答 25 道题目，没有对错之分，只需要诚实地表达自己。题目涵盖：
- 生活作息与习惯
- 社交模式与沟通风格
- 决策方式与计划性
- 情绪管理与压力应对
- 价值观与关系理念

### 3️⃣ 选择性别
完成问卷后，选择你希望生成的 Echo 的性别。

### 4️⃣ 生成档案
AI 将基于你的回答，生成：
- **人格分析** - Big Five 五维人格分数
- **生活细节** - 6 大类生活场景描述
- **行为场景** - 5 个典型行为画面
- **相处画面** - 4 个互动场景
- **匹配原因** - 3 个维度的契合点分析
- **独特细节** - 口头禅、小癖好、治愈食物等

### 5️⃣ 生成形象
AI 将根据人格档案生成对应的视觉形象。首次生成后，可以：
- **智能场景扩展** - 系统会根据 Echo 的人格特质自动生成多样化场景（商场、书店、电影院、游戏厅、网吧、地铁站、便利店等）
- **自定义场景** - 你可以输入自定义场景描述（如"下雨天在商场下避雨"、"在网吧专注打游戏"、"在游戏厅抓娃娃"等）
- **形象一致性** - 所有场景都保持 Echo 的核心形象不变，只更换场景、光线和穿搭

## 💡 Echo 档案包含什么？

每个 Echo 档案都是丰富的、有细节的，包含：

### 📊 人格分析
- Big Five 五维人格分数（开放性、尽责性、外向性、宜人性、神经质）
- 整体性格描述与氛围感

### 🏠 生活细节
- 作息习惯、社交模式、决策风格
- 情绪管理方式、兴趣爱好、日常小习惯

### 🎬 行为场景
- 早晨开启一天的方式
- 晚上结束一天的仪式
- 典型的周末活动
- 压力大时会做什么
- 开心时的表现

### 💞 相处画面
- 日常聊天时的样子
- 你难过时 TA 会怎么做
- 你开心时 TA 会怎么做
- 一起度过周末的画面

### 🤝 匹配原因
- 生活方式契合点
- 情感需求契合点
- 价值观契合点

### ✨ 独特细节
- 口头禅、小癖好
- 最喜欢的时间段
- 治愈食物

## 🎨 输出风格

Echo 的描述风格**文艺与生活并存**，避免空洞的诗意，专注于有细节的真实感：

**✅ 好的描述：**
- "会在深夜给你发长消息，像是把白天攒下的话，在月光下慢慢说给你听"
- "你难过时，TA会安静坐在你旁边，偶尔递个纸巾，像递一份无声的理解"
- "周末会拉着你去逛书店，遇到喜欢的书就坐在角落里一起看，偶尔抬头对视一笑"

**❌ 避免的风格：**
- "如星河般深邃"
- "灵魂的共鸣"
- "注定相遇的缘分"

## 🔒 Echo 的唯一性

**每个 Echo 都是独一无二的：**

- 🔒 生成后永久保存，不可重置或覆盖
- 🎨 初次生成的形象与人格档案同步完成，作为 Echo 的核心特征
- 🖼️ **智能场景生成** - 系统会根据 Echo 的人格档案（生活习惯、兴趣爱好、日常活动等）自动生成多样化场景
- 🎯 **场景多样性** - 从安静的咖啡厅到热闹的游戏厅，从室内的书店到户外的商场，场景丰富多样且符合 Echo 的性格特质
- ✏️ **自定义场景** - 支持输入自定义场景描述，让 Echo 出现在你想要的任何场景中
- 💡 所有场景都保持 Echo 的核心形象不变，只在原有形象基础上更换环境与装扮

## 🚀 快速开始

### 环境要求

- Node.js 20.x 或更高版本
- npm 或 pnpm

### 安装步骤

```bash
# 克隆项目
git clone https://github.com/yourusername/echo.git
cd echo

# 安装依赖
npm install

# 配置环境变量
cp .env.local.example .env.local
# 编辑 .env.local 添加你的 API keys
```

### 运行项目

```bash
# 开发模式
npm run dev

# 生产构建
npm run build
npm start
```

### 部署

项目可一键部署到 [Vercel](https://vercel.com) 或 [Netlify](https://netlify.com)，支持零配置部署。
